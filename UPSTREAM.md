# Upstream references

ClearFolder is independently implemented; no source or binary from the projects below is included.

- https://github.com/bedirhanuyar/FluidDecks — desktop grouping reference (GPL-3.0); not incorporated.
- https://github.com/poncippg-spec/liquidDX11 — clear-glass desktop capture reference (MIT); not incorporated.
- https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-setwindowdisplayaffinity — capture exclusion.
- https://learn.microsoft.com/en-us/dotnet/api/system.windows.media.effects.shadereffect — WPF pixel shaders.
- https://learn.microsoft.com/en-us/dotnet/desktop/wpf/advanced/optimizing-performance-taking-advantage-of-hardware — WPF rendering tiers.
- https://learn.microsoft.com/en-us/windows/win32/api/shobjidl_core/nn-shobjidl_core-ifolderview — desktop grid inspection.
- https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-setwindowpos — desktop overlay ordering.

References describe design research, not upstream code ownership. ClearFolder's own source is released under MIT; future third-party additions require license review.
