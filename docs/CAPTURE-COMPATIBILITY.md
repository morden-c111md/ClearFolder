# 截图与录屏兼容修订（2026-10-12）

用户已确认采用独立背景采集方向：收纳窗口正常参与系统截图和录屏，背景采集不得包含自身，不通过反复隐藏窗口制造闪烁。优先保留动态壁纸、水波、清透玻璃及现有动画；不修改启动项或其他系统设置。

实施顺序：先在本机测试独立桌面窗口的采集结果和更新能力，再选择可验证的采集路径；PrintWindow 返回成功不等于 GPU 动态壁纸被正确捕获。若该路径不支持动态背景，继续调查 Windows Graphics Capture，不把静态回退说成动态支持。采集图像仅存内存。明确的合成诊断可以输出测试图像到 artifacts/test-*。

验证须覆盖：外部屏幕采集看得到窗口；背景无图标/文字递归；动态合成背景实际变化及采集耗时；遮挡暂停、缓冲复用和单帧在途；现有行为测试；正常实例的数据与位置保留。上线前使用 code-reviewer 审查。

本机已选定 PrintWindow 独立桌面宿主采集；小块DC偏移与clip会被目标绘制路径忽略，因此使用复用的完整宿主缓冲后裁剪，不保留错误的局部渲染实现。每组源缓冲内存按宿主宽×高×4字节增长，未来多组宜共享宿主帧。后台单帧在途避免堆积，关闭使用非等待资源接管，阻塞绘制返回后由后台释放。
