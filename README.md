# ClearFolder

Windows 11 桌面悬停收纳工具。2026-10-11 修订版使用 WPF 合成动画和硬件像素着色器，替换主显示路径的 CPU 逐帧折射；清透底板保留背景细节和对比度，鼠标经过的位置产生扩散水波，图标和文字保持清晰。收起和展开使用同一种材质，边缘使用细淡反光线，没有发光外圈或雾白模糊。

## 启动与退出

首次使用请先在项目根目录运行 `powershell -NoProfile -ExecutionPolicy Bypass -File scripts/Build.ps1`，再双击根目录的 `启动 ClearFolder.cmd`，或运行 `artifacts/ClearFolder.exe`。也可使用会在程序缺失时自动构建的 `启动 ClearFolder.ps1`。程序不安装系统组件，默认不注册开机启动项。

按 **Win+D** 查看桌面，默认文件夹在桌面左上区域靠右的位置（初始坐标约 280,100，实际随缩放变化）。任务栏通知区域有 ClearFolder 图标，右键可新建文件夹、显示隐藏的文件夹、退出。

入口自动吸附实际桌面图标网格，拖动后落在最近的空格，避让读取到的桌面图标和其他收纳组。每个收纳文件夹同时维护一个同名 ClearFolder 桌面快捷方式作为 Explorer 的真实占位，玻璃入口覆盖这个快捷方式；因此新安装的图标会避开该格子。Explorer 接口不可用时降级到系统格距；此时无法保证避让，托盘渲染状态可检查来源。

普通应用遮住入口时，按 Win+D 查看桌面；或者双击 ClearFolder 托盘图标，入口会短暂显示在应用上方供定位。托盘提供“临时置于应用上方”用于试用；通常保持关闭。

如果希望重启后自动恢复，请右键托盘，选择 **“登录 Windows 后自动恢复收纳文件夹”** 并确认。默认未启用；只有确认后才写入当前用户的 ClearFolder 登录启动项。再次选择可关闭，不修改其他程序启动项。未启用时双击启动脚本即可恢复保存的布局。

## 基本操作

| 操作 | 结果 |
|---|---|
| 悬停在小文件夹约220ms | 在旁边展开，覆盖原有桌面图标 |
| 鼠标移入面板或经过连接处 | 保持展开 |
| 移出入口、连接区和面板 | 立即开始收回动画 |
| 点击小文件夹 | 立即展开 |
| 单击面板中的项目 | 使用 Windows 默认方式打开 |
| 拖动小文件夹 | 按桌面网格吸附到最近空格并记忆位置 |
| 从桌面或资源管理器拖入真实文件/快捷方式/普通目录 | 移入收纳存储，成功后源位置原图标消失 |
| 按住面板项目并拖出 | 带图标跟随反馈；在桌面空白、资源管理器文件区域或真实文件夹上松手后移动到目标并移除面板条目 |
| 拖出时按Esc或松手回面板 | 取消，原项目继续保留 |
| 右键空白或文件夹 | 添加文件/文件夹引用、重命名、调整对比度、水波开关 |
| 右键某个项目 | 打开、显示原位置、移除引用、明确移动或恢复 |
| 多于16个项目 | 4列分页，滚轮或底部左右页码区域切换 |
| Esc | 收回当前展开面板 |
| 托盘退出 | 有真实收纳项目或未完成移动时禁用；全部拖出/恢复且移动记录完成后允许退出 |
| 托盘“重试完成移动记录” | 写盘失败后在进程内重试日志提交；实际移动中不可用，失败保留文件和记录 |

1～4项使用2列，5～9项使用3列，更多使用4列。最后一行按实际项目显示；6项为3列2行，不保留空白第三行。

## 真实收纳与拖出

直接把自己选择的项目拖入收纳入口或展开面板，程序会将真实项目移动到 `data/files/`。移动成功后，源位置图标消失。支持从桌面和资源管理器明确拖入的普通文件、快捷方式和普通目录；磁盘根目录、虚拟系统图标、符号链接和联接点不接受。只处理你这次实际拖入的项目，不预填内容，也不自动移动已有引用。公共桌面或受保护目录权限不足时明确失败，不擅自提权。

需要保留源文件时，使用右键或托盘中的 **“添加引用”** 菜单。引用与真实收纳可同时存在，已有引用保持原状态。对旧引用重新主动拖入同一项目，才将它转为真实收纳。

从面板拖出时，超过拖动阈值后显示跟随鼠标的图标；在桌面空白、资源管理器当前目录的文件列表空白处，或真实文件夹图标上松手，才执行移动。取消、返回面板、无法确认目标、权限不足或同名冲突时保留收纳项目。回收站、此电脑、导航栏、标题栏和其他应用不接收这种拖出操作。多标签页路径无法唯一识别时会拒绝，请使用独立的资源管理器窗口。

旧引用被你主动拖到另一目录时，会移动其真实源项目；拖回源项目原本所在的目录时只移除面板引用。恢复到原位置也可使用项目右键的恢复操作。目标重名时拒绝覆盖。退出程序不会自动移动收纳文件；文件继续保存在 `data/files/`，下次启动恢复现有布局。

**不要直接删除或搬走 `data/`。** 移动失败或中途取消且出现部分目标时，程序会保留 `pending-move.json` 和两端文件，停止后续移动。请检查源/目标后处理，不要自行清空恢复记录。损坏配置不会自动重置；`layout.json.bak` 是上一次布局备份。

## 当前实现边界

- 这是独立的 C# / WPF 原生实现，托盘、管理对话框使用 WinForms；研究过 FluidDecks 和 liquidDX11，没有复制其源码，不是它们的 fork。
- 系统动画时钟驱动从入口舒展、轻微回弹、吸回入口，支持收放中反向。水波使用 PS 3.0 硬件像素着色器，硬件不可用时明确降级；托盘“查看渲染状态”可检查当前路径。不承诺固定帧率或苹果原生材质。
- 背景小区域定期采样在后台完成，不再每帧用 CPU 遍历像素；正常运行不保存采样画面到磁盘。水波只影响背景，最多保留三组短暂扩散波纹。
- 动态壁纸优先使用约30ms后台采样目标，复用捕获Bitmap/Graphics和显示WriteableBitmap，最多一个任务在途。采样仍是CPU屏幕拷贝，目标间隔不等于实际更新率或呈现FPS；完全遮挡时暂停、露出恢复。托盘使用蓝青色玻璃文件夹图标。
- 入口正常驻留在桌面层，普通应用在其上方。拖入文件时请使用未被应用遮住的入口区域，收到拖入后保持显示。定位、管理菜单和拖动时可短暂提升。不同桌面增强软件、全屏和 Explorer 重启仍需实际兼容性反馈。
- 每个收纳组创建一个可见的桌面 `.lnk` 占位对象，目标是当前 ClearFolder 可执行文件，不包含任何预填项目；玻璃窗口覆盖它并使用创建后 Explorer 返回的网格位置。删除或移动该快捷方式会让该组在下次启动时重新创建占位。
- 使用系统 DPI 缩放。几何布局已限制工作区；混合 DPI 跨显示器的字体尺寸仍有局限。
- 玻璃排除自身捕获用于防止画面递归，因此普通截图/录屏可能看不到收纳窗口。程序内部渲染预览可检查材质，真实手感应直接试用。
- 后台优先读取 `.url` 的指定图标、`.lnk` 的显式图标或目标图标；首帧可能暂时显示后备图标，读取完成后主动刷新。无可用图标时保留可点击的后备图标，不删除原文件。
- 拖出使用程序自己的鼠标捕获与目标识别，然后执行带恢复日志的移动；不会把项目交给未知目标执行任意 OLE 删除操作。目标识别依赖 Windows Shell 和辅助功能接口，不能确认真实目录时拒绝移动。

## 开发和验证

系统自带 .NET Framework 4.x C# 编译器即可，无需额外安装。

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/Build.ps1
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/Test.ps1
artifacts/ClearFolder.exe --capture-test
artifacts/ClearFolder.exe --interaction-test
artifacts/ClearFolder.exe --drop-test
artifacts/ClearFolder.exe --transfer-test
artifacts/ClearFolder.exe --usability-test
artifacts/ClearFolder.exe --icon-test
artifacts/ClearFolder.exe --tray-test
artifacts/ClearFolder.exe --dynamic-background-test
artifacts/ClearFolder.exe --ripple-menu-test
artifacts/ClearFolder.exe --animation-test
artifacts/ClearFolder.exe --smoke
artifacts/ClearFolder.exe --render-preview
```

捕获和原生 UI 测试需运行在交互式桌面，受限后台桌面会报句柄无效。`--animation-test` 以自己的合成棋盘背景验证实际水波像素变化、动画中断及窗口层级，输出帧回调间隔（不是实测呈现FPS）；测试会短暂移动鼠标，结束后恢复。

收起入口按原桌面图标中心放大约20%，继续使用同一格距吸附；边缘会限制在工作区内。入口到展开面板之间有独立的宽鼠标通路，横向或斜向经过空隙时保持展开；通路不改变三角外观、不拦截桌面点击，被其他窗口覆盖时不维持展开，真正离开共同区域立即收起。

右键入口的“鼠标水波”显示当前状态，勾选表示已开启；不可用时明确显示当前环境不可用。水波为背景折射加局部短暂明暗起伏，使暗色背景也可见，不增加整体白雾，图标与文字保持清晰。`--ripple-menu-test` 在独立合成数据中实际点击开关，检查持久化及波纹发射，不修改正常布局。需要显式启用已有布局水波时可单次运行 `artifacts/ClearFolder.exe --enable-ripples`（须先退出已有实例），后续正常启动保留用户设置。

`--render-preview` 保留首版 CPU 离线预览，用于比较布局，不代表新版 GPU 水波。WPF 的内部静态导出显示布局和清晰背景，不能捕获 HardwareOnly 着色器；实际水波由合成场景屏幕采样验证。诊断截图仅由明确诊断命令输出，正常运行不将桌面画面写盘。

行为测试只操作 `artifacts/test-*` 中的合成文件，测试目录保留以便检查，不自动删除。最新验证结果见 `docs/VERIFICATION.md`。
